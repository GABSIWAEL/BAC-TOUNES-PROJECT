# BacTounes

**BacTounes** is a web application designed to provide educational resources, study guides, and past Baccalaureate (BAC) exam papers for students in Tunisia.  
The project currently focuses on **Science and Technology (SVT)** subjects, offering organized and easily accessible PDF materials.

## 🎯 Features

- Browse and download **past exam papers** (SVT Baccalaureate)
- Access **summaries and study notes** for each chapter
- Clean and **user-friendly interface**
- Fully **responsive design** for mobile and desktop
- Organized and categorized PDF resources

## 📁 Project Structure

```
bactounes/
├─ src/
│  ├─ assets/
│  │  ├─ pdfs/         # PDF resources (exams, summaries, notes)
│  │  └─ sass/         # Stylesheets and theme files
│  ├─ index.html       # Main HTML entry
│  └─ main.ts          # Angular bootstrap file
├─ docker-compose.yml   # (Optional) Docker setup
├─ tsconfig.json        # TypeScript config
└─ README.md            # Project documentation
```

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/GABSIWAEL/bacTounes.git
cd bacTounes
```

### 2️⃣ Install Dependencies (Angular)
```bash
npm install
```

### 3️⃣ Start the Development Server
```bash
ng serve
```

### 4️⃣ Open in Browser
```
http://localhost:4200
```
